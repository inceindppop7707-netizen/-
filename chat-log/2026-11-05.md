**部署过程摘要：**

她通过阿里云Workbench网页终端连上服务器后，我一步一步给她指令：

1. `git checkout claude/miao-4ku4ii` — 之前clone的是默认分支（空的），切到有代码的分支
2. nvm安装Node.js 20 — apt装Node时服务器只有0.5GB内存OOM了，改用nvm成功
3. `cd ~/linmiao/server && npm install` — 安装依赖
4. 用nano手动创建`.env`文件（heredoc方式在终端上出了问题，终端卡死过一次）
5. `node index.js` — 第一次跑报错：Supabase需要WebSocket但Node 20没有原生WebSocket
6. `npm install ws` — 装了ws包但用require导入不行（ESM模块）
7. 我这边改了index.js开头加`import WebSocket from 'ws'; globalThis.WebSocket = WebSocket;`，push后她`git pull`
8. `node index.js` — **成功！** "林苗 server running on :3000"
9. pm2配置：`pm2 start index.js --name linmiao`、`pm2 startup`、`pm2 save`
