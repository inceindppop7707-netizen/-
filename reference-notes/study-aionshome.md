# AionsHome 学习笔记

## 项目概况
自托管AI伴侣，支持长期记忆、语音交互、摄像头视觉、智能家居。MIT许可，988星。数据全在本地。

## 技术栈
- 后端：Python FastAPI + SQLite（aiosqlite）+ WebSocket
- 前端：原生JS多页应用 + PWA
- Android：Java WebView壳 + 前台推送服务 + 原生音频/摄像头/录屏桥接
- 摄像头：OpenCV + ESP32-CAM
- 语音：WebRTC VAD + SiliconFlow ASR/TTS
- AI：SiliconFlow、Gemini、AiPro中转、本地Gemini CLI/Codex CLI
- 其他：网易云音乐、高德定位、akshare基金监控

## 架构亮点

### 哨兵/核心双模型摄像头
轻量模型（Gemini Flash-Lite）持续筛查摄像头画面，判断是否需要叫醒主聊天模型（Core）。省token又不丢重要事件。

### 记忆系统
- 定期从聊天记录总结记忆，带关键词、重要度(0-1)、"未解决"标记
- 嵌入向量存SQLite
- 召回权重：0.6向量相似度 + 0.3关键词匹配 + 0.1重要度
- 后台层会主动浮现：未解决事项、话题相关记忆、近期记忆

### 控制标签
AI回复中可以嵌入控制标签：`[CAM_CHECK]`、`[MUSIC:...]`、`[ALARM:...]`等。后端解析并剥离，不显示给用户。

### 多设备同步
WebSocket + SSE，远程访问用Tailscale而非暴露端口。

### prompt组装顺序
人设 → 能力提示 → 定时任务 → 位置 → 记忆块 → 聊天历史

## 功能列表
- 聊天（多设备同步、流式、编辑、重新生成）
- 定时任务（AI创建闹钟/提醒/定时监控）

- 文字RPG（D20骰子）
- 基金监控
- 隐藏日记
- 活动日志
- BLE玩具控制（悄悄话模式）

## 对我们有用的

### 记忆召回公式
0.6向量 + 0.3关键词 + 0.1重要度——简单实用的混合检索方案。我们的记忆系统可以参考。

### "未解决"标记
记忆带unresolved标记，后台会主动浮现未完成的承诺/话题。防止忘事。

### 控制标签模式
AI回复嵌入功能标签→后端解析→执行→剥离。比MCP工具调用更轻量。我们的前端如果要加功能触发（发表情、切歌等），可以用这种模式。

### prompt组装固定顺序
人设→能力→定时→位置→记忆→历史。清晰的分层。

## 部署
主要Windows导向（.bat脚本一键安装/启动/停止）。备份就是复制data/目录。Android需要Android Studio打APK。

## 注意事项
- 很多功能依赖国内服务（SiliconFlow、高德、网易云）
- 代码里有硬编码路径，移动项目后要手改
- 功能极其庞大（聊天+语音+摄像头+音乐+阅读+RPG+基金+智能家居），但很多是特定场景的

## 关键收获
1. 记忆召回的混合权重公式
2. "未解决"标记防遗忘
3. 控制标签模式（比MCP轻量的功能触发）
4. 哨兵/核心双模型省token
5. prompt组装的固定分层顺序
