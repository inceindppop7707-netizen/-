# study: Saekisui/binaural-voice

把单声道TTS语音渲染为双耳立体声，让声音像贴在耳边说话，可以在头部周围移动。仅耳机有效。

## 项目概览

- **语言**：Python（~140行核心 + speak.py）
- **许可**：AGPL-3.0
- **依赖**：numpy, scipy; ElevenLabs（可选，speak.py用）
- **HRIR数据**：Neumann KU100假人头近场实测（CC BY 4.0），水平面1°间隔，距离0.25-1.5m

## 架构

两个文件分工明确：
- **speak.py**：解析位置标签 → 调ElevenLabs TTS → 输出带时间戳的cue列表 → 调binaural_voice.py
- **binaural_voice.py**：加载HRIR → 按cue列表渲染空间音频

### 位置标签系统

6个中文标签：`[左耳]` `[右耳]` `[脑后]` `[面前]` `[贴近]` `[退开]`
- 可以写在句首或句中
- 没有标签时随机选择走位模式（停在一只耳朵、绕行、从后面来、从前面来）

### 渲染管线

1. 加载HRIR数据（ku100_nearfield_circ360.npz）
2. 重采样到输入采样率
3. 语音活动检测：10ms帧，RMS > 5%峰值 = 有声，0.4s内间隙桥接
4. **移动只在有声音时推进**，停顿时保持位置
5. 1024采样Hann窗，50%重叠
6. 每帧：查位置 → 查HRIR（距离线性插值）→ fftconvolve
7. 重叠相加 → RMS匹配 → 限幅-1dBFS → 16bit WAV

### 关键参数

| 参数 | 值 | 含义 |
|------|-----|------|
| NEAR/FAR | 0.25m / 0.5m | 贴近/退开的距离 |
| HALF_TURN | 4.5s有声时间 | 180°转一半的时间 |
| DIST_MOVE | 1.5s | 距离变化的时间 |
| DRIFT_DEG/M | 小值 | 停留时的微小摆动 |

### 移动逻辑

- `az_path()`：选更短的转向方向，但**永远不从正面穿过**（从脑后绕）
- `track_at()`：余弦缓动
- 微小漂移（drift）让停留不死板

### speak.py的ElevenLabs集成

- 用`with-timestamps`端点，同时拿到音频和逐字符时间戳
- 发TTS前先剥掉位置标签（eleven_v3会把括号文本当表演指令）
- 按字符偏移把标签映射回时间轴
- 默认pcm_24000（pcm_44100需Pro以上）

## 局限

- 仅耳机，仅水平面
- 最近25cm（通用假人头，部分人前后混淆）
- 24kHz输出，高频上限12kHz
- TTS耳语缺口腔音和呼吸细节
- M3 Pro渲染16秒约1秒——适合语音条，不适合实时

## 对我们项目的价值

**直接相关**：
- 未来做ASMR/亲密语音时，这是现成的空间化方案
- 位置标签系统可以直接用——在对话脚本里写`[左耳]``[右耳]`就行
- 和ai-voice-breath配合：先用ai-voice-breath调教语音质量，再用binaural-voice做空间化

**技术启发**：
- 语音活动检测决定移动时机——停顿不动是很自然的设计
- 余弦缓动 + 微漂移让移动不机械
- HRIR距离插值实现远近感
- 绕后不穿前的移动路径选择

**限制**：
- Python离线处理，不是实时Web方案
- 要集成到前端需要WebAudio API重写（但算法可以搬）
