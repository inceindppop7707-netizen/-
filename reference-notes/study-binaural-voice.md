# binaural-voice (Saekisui/binaural-voice) 学习笔记

## 项目概述
把单声道TTS语音渲染成双耳立体声——让声音贴在耳边，能绕头移动。AGPL-3.0。
用于耳机场景，配合ElevenLabs TTS。

## 技术栈
- Python + numpy + scipy（信号处理）
- 近场HRIR数据：Neumann KU100假人头，25cm-1.5m，CC BY 4.0
- ElevenLabs with-timestamps端点
- ffmpeg, h5py

## 架构——两步管线

### speak.py
- 剥离位置标签（`[左耳]`/`[脑后]`/`[贴近]`等）
- 干净文本发ElevenLabs
- 字符时间戳把标签映射到时间点

### binaural_voice.py
- 单声道WAV + JSON cue列表 → HRIR卷积 → 双耳音频
- 只在有语音时移动声源（音频能量检测停顿）
- 移动绕后脑走，不穿前方
- random_cues()：没标签时随机移动

## 限制
- 仅耳机、水平面、最近25cm、24kHz
- 通用假人头数据（部分人前后反转）
- 离线渲染（16秒≈1秒处理）

## 值得学的

1. **位置标签嵌入脚本**——`[左耳]`写在台词里，TTS不读但渲染时定位
2. **字符级时间戳**——ElevenLabs返回每个字符的时间，标签精确映射
3. **只在说话时移动**——检测能量判断停顿，避免安静时跳位
4. **绕后脑移动**——换耳走后面更自然
5. **标签系统设计**——在文本中嵌入元数据的通用模式
