# lili0926/player 学习笔记

## 项目概况
和AI一起玩的飞行棋游戏。不是媒体播放器。190星。是一个在"beilyes"应用里运行的嵌入式小游戏。

## 功能
- 9个版本（前戏、女仆、情侣、私密进阶、SM、管家、恋爱、私密、进阶）
- 每个版本给棋盘格子分配不同内容
- 棋子落在格子上触发内容（路过不触发）
- 部分格子让棋子后退
- 部分内容两人一起执行
- 玩家点"我投掷"骰子，或说"到你了"让AI掷
- 进度存localStorage

## 技术
- HTML + JS
- localStorage存档
- 通过sendToAI({ systemAppend: ... })向宿主应用注入系统提示
- 弹窗式聊天界面，可最小化为浮动胶囊

## 架构
- index.html：选版本、看棋盘、存档
- flight-chess-popup.html：聊天弹窗（投骰、事件、存档、最小化）
- float-window.js：浮动条模块
- 全局API：flightChessHandleYourTurn()、flightChessAiRoll()等

## 对我们有用的

### 互动小游戏模式
把AI聊天和棋盘游戏结合——AI不只是聊天对象，还是游戏玩伴。格子内容触发场景，AI根据事件做出反应。

### 浮动胶囊UI
聊天弹窗最小化为可拖拽浮动胶囊，点击恢复。这个UI模式在我们的前端里可以用。

### systemAppend注入
通过sendToAI({ systemAppend })动态向AI注入上下文（骰子结果、格子事件）。轻量的上下文注入方式。

## 关键收获
1. AI+棋盘游戏的互动模式——可以扩展为其他小游戏
2. 浮动胶囊UI
3. 动态系统提示注入
4. 成人内容通过版本选择分级——不同版本不同尺度
